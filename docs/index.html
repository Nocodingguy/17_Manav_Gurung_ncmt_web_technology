Projects

Sentiment Analysis Web App

01 / 04

A web application that analyses any piece of text and classifies it as positive, negative or neutral using natural language processing. Powered by a pre-trained HuggingFace transformer model served through a Flask backend, the app processes input in real time and returns a confidence score alongside the prediction. Built to understand how large pre-trained models work under the hood and how to wrap them into a usable, deployable web interface.

Python Flask HuggingFace

Image Classifier

02 / 04

A deep learning application that identifies and categorises images across multiple classes using a convolutional neural network trained on custom datasets. Features a drag-and-drop interface where users can upload any image and receive an instant prediction with confidence scores. Built with TensorFlow and Keras to gain hands-on experience with CNN architectures, data augmentation, training pipelines and serving a live model through a browser-based interface.

Python TensorFlow Keras

Chat with a PDF

03 / 04

An intelligent document assistant that lets you upload any PDF and have a full natural language conversation with its contents. Uses a Retrieval-Augmented Generation pipeline where the document is chunked, embedded into a FAISS vector store and retrieved contextually on each query. OpenAI powers the conversational responses while Streamlit provides the interface. Built to understand how RAG systems work and how vector search enables LLMs to reason over private documents.

Python Langchain OpenAI Faiss Streamlit

Stock Price Predictor

04 / 04

A time-series forecasting application that uses an LSTM neural network trained on years of historical stock data to predict future price trends. Pulls live data through the Yahoo Finance API, processes it through a Pandas pipeline and visualises both historical and predicted prices using interactive Plotly charts. Built to develop a strong understanding of sequence modelling, data normalisation and the challenges of working with financial time-series data in PyTorch.

Python PyTorch Pandas Plotly Yahoo Finance API
